# KOKO ACCESSORIES — Auto-Saving Car Accessories Storefront & Admin Portal

All files are stored in **`D:\projects\koko accessories\`**.

---

## ✦ How Automatic Saving Works

Whenever you use the Admin Panel to:
- Drag & drop or upload photos
- Add new car accessories
- Edit or delete accessories
- Add or remove car brands and categories

**It saves automatically into your `D:` drive files:**
1. Photos are automatically saved as files inside **`D:\projects\koko accessories\images\`**.
2. The catalog database is automatically written directly to **`D:\projects\koko accessories\products.js`**.
3. It also saves to your browser memory so everything stays 100% in sync.

---

## ✦ How to Launch

Simply double-click:
👉 **`Open KOKO (Auto-Save).bat`** (inside `D:\projects\koko accessories\`)

This opens your browser and keeps the auto-saver running so **everything you do is saved immediately to your D: drive**.

---

## ✦ File Structure

| File | Purpose |
| :--- | :--- |
| **`Open KOKO (Auto-Save).bat`** | **Recommended**: Double-click to start with automatic direct saving to `D:`. |
| **`index.html`** | The customer storefront (select car, view accessories). |
| **`admin.html`** | The admin portal (drag-and-drop photos, add accessories). |
| **`products.js`** | The database file where all accessories and car brands are saved. |
| **`images/`** | Where your uploaded accessory photos are saved. |
| **`server.py`** | Lightweight auto-save background helper (built into Windows Python). |
| **`styles.css`** | Zara-style editorial fashion stylesheet. |
| **`app.js`** | Customer storefront engine. |
| **`admin.js`** | Admin panel engine with direct auto-sync. |
